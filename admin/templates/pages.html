Upstream DNS

Upstreams are set in the resolver's own configuration file and applied on restart. They are shown here rather than edited, because a dashboard that could rewrite the resolver's config would need write access to it — and this process deliberately has none.

Edit /etc/private-dns/config.yaml, then systemctl restart privatedns-resolver.
